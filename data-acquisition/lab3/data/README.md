# Labor 3 andmed

`drops.csv` sisaldab ühte rida iga füüsiliselt mõõdetud tilga kohta. Ettevalmistusfailis on ainult päis; mõõtmata ridu ei lisata.

Iga tilga rõhukõver salvestatakse sama `drop_id` järgi deterministliku nimega:

```text
curve_drop_0001.csv
```

See on repo failinimekonventsioon, mitte mõõdetud tulemus. `drops.csv` välja `curve_file` väärtus peab viitama täpselt sama tilga rõhukõverale. Rõhukõvera lõplikud veerud määratakse pärast Labori 2 CSV-vormingu kontrollimist; toorproovid ja algsed ajatemplid säilitatakse muutmata.
