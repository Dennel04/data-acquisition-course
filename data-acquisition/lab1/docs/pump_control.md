# Pump control — измерения

## 12.09.26 — Targa kasti logi (часть 3, ACU2-B заводской "умный" ящик)

**Метод:** T-отвод в выходную трубку ACU2-B, присоска руками прижата к
стеклу, трубка целая. Насос запущен **одной** командой всасывания через
CLI (`mg400 pump suck`) — дальше ACU2-B управляет собой сам, руки от
присоски и CLI убраны на всё время лога. Логировал `python/logger.py`
(`--mode off --dry-run` — Atom только слушает давление, ничего сам не
решает и не шлёт в mg400-base). Сырые данные: [`data/lab1_smartbox_acu2b_12.09.26.csv`](../data/lab1_smartbox_acu2b_12.09.26.csv).

**Параметры лога:** 35800 строк, 358.0 с (5.97 мин), частота подтверждена
~100 Гц (соответствует части 2 задания: 10мс цикл).

**Обнаруженные переключения** (сглаживание скользящим средним по 15
отсчётам, порог значимого перепада — 3 кПа, чтобы не ловить ADC-шум):

| t, мс | p, кПа | Событие |
| :--- | :--- | :--- |
| 1 567 574 | -4.23 | старт (насос ещё не тянул) |
| 1 571 724 | -91.51 | насос дотянул до предела и встал |

Дальше — **ровно плоская линия** ещё ~353 секунды. Повторного включения
насоса за оставшееся время лога не было ни разу.

## Пять чисел (по итогам этого теста)

| Величина | Значение | Комментарий |
| :--- | :--- | :--- |
| **väljalülitusrõhk** (давление выключения) | **≈ -91.5 кПа** | надёжно, один явный переход |
| **sisselülitusrõhk** (давление включения) | **не зафиксировано** | насос ни разу не включился повторно за 5.97 мин — утечка через присоску практически нулевая на этом окне теста, порог включения не достигнут |
| **pumba tööaeg** (время работы насоса) | **~4.2 с** | время набора вакуума от старта до предела |
| **seisuaeg** (время простоя) | **≥ ~353 с** | нижняя граница снизу, не точное число — тест закончился раньше, чем случился повторный цикл |
| **käivitusi minutis** (включений в минуту) | **≈ 0** | за это конкретное окно теста |

**Вывод:** это валидный результат, не ошибка измерения — присоска на
стекле держит настолько хорошо, что за почти 6 минут ACU2-B ни разу не
пришлось перезапускать насос. Короткоцикличности ("lühitsükkel") в этом
сценарии нет и близко — совсем другая картина ожидается в сценарии
"napp õhus" (присоска в свободном воздухе, максимальная утечка), который
всё ещё предстоит измерить для части 4.

**Дальше:**
- Если для отчёта нужна и цифра sisselülitusrõhk — либо логировать
  дольше (пока утечка сама не дотянет до порога), либо намеренно
  чуть приподнять присоску (контролируемая небольшая утечка), чтобы
  спровоцировать повторный цикл — не обязательно по заданию, но полезно
  для полноты картины.
- Часть 4 (собственный ящик): три сценария holding-теста (napp klaasil /
  napp õhus / voolik korgiga) ещё предстоят — это уже с командным
  MG400-ящиком, не с ACU2-B.

## 12.09.26 — Holding-тест, собственный MG400-ящик, сценарий 1: napp klaasil

**Метод:** T-отвод в трубку вашего (обычного, не ACU2-B) пумп-бокса,
присоска руками на стекле. Вакуум включён вручную (кнопка на ящике /
`mg400 pump suck`) до максимума, затем выключен вручную в момент пика —
дальше просто логировали пассивную утечку до возврата к атмосфере, без
дальнейшего вмешательства. Логировал `python/logger.py --mode off
--dry-run`. Сырые данные: [`data/lab1_ownbox_glass_12.09.26.csv`](../data/lab1_ownbox_glass_12.09.26.csv).

**Параметры лога:** 39829 строк, 398.3 с (6.64 мин), ~100 Гц подтверждено.

| Событие | t, мс | p, кПа |
| :--- | :--- | :--- |
| Старт (до включения) | 1 610 491 | -1.12 |
| Насос выключен (пик вакуума) | 1 641 651 | **-83.06** |
| Восстановилось до атмосферы (≥ -2 кПа) | 1 952 331 | -1.97 |

**Числа для этого сценария:**

| Величина | Значение |
| :--- | :--- |
| Достигнутый максимум вакуума | **-83.06 кПа** |
| Время работы насоса (до пика) | **~12–16 с** |
| Время утечки обратно до атмосферы (простой) | **310.7 с (~5.18 мин)** |

**Вывод:** в отличие от теста с ACU2-B (где утечка вообще не успела
проявиться за ~6 минут), здесь присоска на стекле **полностью
восстановилась** до атмосферного давления за разумное время — значит на
этом конкретном ящике/присоске утечка через контакт присоска-стекло
заметно больше, чем через ACU2-B. Это даёт полную кривую утечки, из
которой можно выбирать полосу (on/off kPa) и минимальное время простоя
для части 4, а не только нижнюю границу, как в тесте с ACU2-B.

**Дальше:** сценарии 2 (napp õhus — присоска в свободном воздухе) и 3
(voolik korgiga — трубка с заглушкой) ещё предстоят, той же методикой.

## 12.09.26 — Holding-тест, собственный MG400-ящик, сценарий 2: napp õhus

**Метод:** та же T-схема, но присоска висит в свободном воздухе, ничего
не касается (максимальная негерметичность, полная противоположность
сценарию 1). Вакуум включён вручную, оставлен работать дольше обычного,
пока давление не вышло на плато (насос не может тянуть глубже против
свободно текущего воздуха), затем выключен вручную. Логировал
`python/logger.py --mode off --dry-run`. Сырые данные:
[`data/lab1_ownbox_air_12.09.26.csv`](../data/lab1_ownbox_air_12.09.26.csv).

**Параметры лога:** 9376 строк, 93.75 с.

| Событие | t, мс | p, кПа |
| :--- | :--- | :--- |
| Плато (последние ~5с перед выключением) | — | среднее **-12.4 кПа** (шум -9…-15) |
| Насос выключен (пик) | 46 914 | **-15.46** |
| Восстановилось до атмосферы (≥ -2 кПа) | 63 874 | -1.97 |

**Числа для этого сценария:**

| Величина | Значение |
| :--- | :--- |
| Максимум вакуума, который насос вообще способен вытянуть против открытого конца | **≈ -12…-15 кПа** (плато, не растёт дальше) |
| Время утечки обратно до атмосферы (простой) | **17.0 с** |

**Вывод:** ровно то, что и ожидалось — на порядок мельче максимум (-15
против -83 кПа на стекле) и на порядок быстрее восстановление (17с
против 310.7с). Это подтверждает, что именно контакт присоска-поверхность
определяет герметичность системы, а не сам насос/клапаны — совпадает с
выводом из части 4 задания про важность плотного прилегания присоски.
Отдельно интересно, что даже здесь давление **не возвращается к 0
мгновенно** — трубка и сам насос дают заметную (17с) постоянную времени
сами по себе, это нижний предел скорости даже при полностью открытом
конце.

**Дальше:** сценарий 3 (voolik korgiga — трубка с заглушкой) — ожидаем
самую медленную утечку из всех трёх (или вообще без неё).
